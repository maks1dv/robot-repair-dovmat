**Що зрозумів про тригери, public і private:**
- **Тригери** не зупиняють об'єкт, а лише реєструють перетин меж іншим колайдером.
- Модифікатор **`public`** робить змінні доступними в Inspector та з інших скриптів, а **`private`** приховує їх від зовнішніх змін.
- Властивості тільки для читання (`public int health { get { return currentHealth; } }`) дозволяють безпечно надавати доступ до даних іншим скриптам без ризику їх некоректної модифікації.

**Яке значення Time Invincible обрав і для якого гравця:**
Обрано значення **1.5 секунди**. Це оптимальний баланс для гравців, які тільки знайомляться з 2D-аркадами: є час зреагувати на небезпеку та відійти, але затримка в зоні все одно залишається відчутною карою.

  - ### 20.11.2026 — Лабораторна 8: механіка-твіст
- **Правило твіста:** Коли гравець наступає на плиту перемикача (`Switch`), то двері (`Door`) вимикаються на `Open Time` секунд, після чого зачиняються знову.
- **Який твіст обрав і чому:** Обрав перемикач з таймером (`TimedSwitch`), оскільки він змінює дію пересування у core loop: гравець не може просто пройти коридором, а мусить розрахувати маршрут і встигнути пробігти крізь двері до завершення таймера.
- **Tuning Table та числа, які змінив плейтест (було — стало — чому):**
  - Діапазон `Open Time`: `1.5` с (мінімум, фізично неможливо встигнути) — `10.0` с (максимум, таймер не створює виклику).
  - `Open Time`: було `4.0` с — стало `3.0` с — під час перших двох проходжень за 4 секунди гравець проходив двері із великим запасом без ризику, а зменшення до `3.0` с зробило ділянку динамічною, але чесною (результати 3 проходжень: час пробігу ділянки — 2.3 с, 2.5 с, 2.4 с; залишок здоров'я на фініші — 4/5, 3/5, 5/5).
- **Перевірка за 3 питаннями плейтесту:**
  1. Гравець помічає плиту одразу завдяки контрастному помаранчевому кольору та зміні на зелений при активації.
  2. Зв'язок між натисканням плити та зникненням червоних дверей зрозумілий з першої спроби.
  3. Рівень можна пройти до кінця без помилок, але через закритий прохід твіст обов'язково залучає гравця до механіки таймера.
- **Що зламалося і як полагодив:**
  - На об'єкті `Door` спочатку був відсутній `Box Collider 2D`, через що робот міг проходити крізь зачинені двері без натискання плити — додав `Box Collider 2D` без `Is Trigger` та виставив масштаб дверей по висоті проходу (`Scale Y = 2`).
- **Висновки:**
  - Реалізовано та протестовано механіку-твіст `TimedSwitch` із винесенням параметрів (`Active`, `Door`, `Open Time`) у публічні поля Inspector та створенням базового префаба `Switch` і варіанта `Switch_Fast`. Винесення числових параметрів в Inspector дозволило швидко підібрати баланс часу під час трьох плейтестів без зміни вихідного коду.
