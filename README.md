**Що не вийшло або забрало найбільше часу:**
Найбільше часу пішло на відлагодження зони шкоди: спочатку робот втрачав усе здоров'я за секунду, бо я забув додати перевірку `if (amount < 0)` на початку функції `ChangeHealth`. Також розібрався, чому важливо ставити перевірку `controller != null` першою в логічному `&&`.

**Що зрозумів про тригери, public і private:**
- **Тригери** не зупиняють об'єкт, а лише реєструють перетин меж іншим колайдером.
- Модифікатор **`public`** робить змінні доступними в Inspector та з інших скриптів, а **`private`** приховує їх від зовнішніх змін.
- Властивості тільки для читання (`public int health { get { return currentHealth; } }`) дозволяють безпечно надавати доступ до даних іншим скриптам без ризику їх некоректної модифікації.

**Яке значення Time Invincible обрав і для якого гравця:**
Обрано значення **1.5 секунди**. Це оптимальний баланс для гравців, які тільки знайомляться з 2D-аркадами: є час зреагувати на небезпеку та відійти, але затримка в зоні все одно залишається відчутною карою.
